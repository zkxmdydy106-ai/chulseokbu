# 출석부

교사용 폰 출석부 웹앱 — 주소: https://zkxmdydy106-ai.github.io/chulseokbu/

- **교과 반**: 날짜 → 교시 → 반 → 학생 칸을 눌러 출석·결과(/)·출석인정(Ø), 길게 눌러 사유
- **담임 반**: 나이스 출결 구분 16가지 + 세부 사유(생리·교외체험학습·행사·교외활동…) + 필요 서류 제출 체크, 교외체험학습 누적 일수, 서류 규칙은 학교마다 설정
- **내보내기**: 나이스용 엑셀(과목별출결·일일출결) → 크롬 확장 '나이스·에듀파인 도우미'로 나이스에 입력
- **명단·연락처**: 도우미가 나이스에서 뽑은 명단 파일(번호·이름), 엑셀·CSV 또는 내 구글 시트의 연락처 → 학생 칸에서 전화·문자

## 개인정보
- 이 저장소에는 코드만 있습니다. 반·명단·출결·연락처는 **각자 폰의 브라우저 안에만** 저장되고 어디로도 보내지 않습니다.
- 구글 시트 불러오기는 선생님 본인 구글 계정으로 실행되는 Apps Script(스프레드시트 읽기 전용)가 그 시트를 읽어 이 앱 창으로만 넘깁니다.
- 내보낸 엑셀·백업 파일에는 학생 이름이 들어 있습니다. 학교에서 허용한 방법으로만 옮겨 주세요.
